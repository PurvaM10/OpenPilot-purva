# DevPortfolio Agent Workflow

The agent follows this workflow:

## 1. Find Open-Source Opportunities

Search for relevant open-source GitHub repositories and beginner-friendly issues matching the contributor's skills, interests, and technologies.

## 2. Analyze Repository & Issue

Analyze the selected repository and issue, including requirements, technologies, contribution guidelines, relevant components, and testing requirements.

## 3. Plan Contribution

Create a concrete implementation plan based on the issue and repository guidelines.

## 4. Generate Contribution

Generate proposed code, documentation, tests, bug fixes, feature implementation guidance, or other appropriate contribution material.

## 5. Validate Contribution

Check the proposed contribution against the issue and repository information. Identify verified information and anything requiring human review.

## 6. Generate PR + Portfolio

Generate:

- Pull request title
- Pull request description
- Change summary
- Testing instructions
- Repository and issue links
- Technologies
- Skills demonstrated
- Impact
- Portfolio summary
- README entry
- Changelog entry
- Improvement suggestions

All contribution material is treated as a draft until reviewed by the developer.
